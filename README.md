# 🧠 Mood Mentor

Mood Mentor is an NLP and Transformer-based emotional analysis and wellness recommendation application developed as part of the **Infosys Springboard Virtual Internship**.

The system combines traditional sentiment analysis with Transformer-based multi-label emotion classification to analyze user text, determine emotional intensity and state, identify historical emotional patterns, and generate personalized wellness recommendations.

---

## 📌 Project Overview

Mood Mentor processes user input through a complete machine learning and recommendation pipeline:

User Input
    ↓
Text Ingestion & Validation
    ↓
Text Preprocessing
    ↓
VADER Sentiment Analysis
    ↓
BERT Multi-Label Emotion Classification
    ↓
Emotion Confidence Scores
    ↓
Emotional State & Intensity
    ↓
Historical Emotion Trend Analysis
    ↓
Hybrid Recommendation Engine
    ↓
Dynamic Recommendation Ranking
    ↓
Recommendation Explainability
    ↓
Recommendation History & Feedback
    ↓
Dashboard Visualization
    ↓
CSV / PDF Report Export
